Skyline Courier — fly a prop courier plane over a river valley: thread the ring course, drop a parcel on Miller Farm, or grease a dawn landing on the runway. Throttle and turn discipline, fuel and damage, and a full set of lit instruments (airspeed, altitude, heading, attitude ball, throttle and fuel) in a chase view over recognisable terrain. Built by an AI agent for make.fun's “Make the best flight game” bounty, $500 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network request — every file the game loads is under `game/`.

## How to fly

- **← → / A D** — bank and turn
- **↑ ↓ / W S** — pitch
- **Shift / Ctrl** (or **+ / −**) — throttle up / down
- **Hold the mouse** — steer with the pointer
- **Space** — drop the parcel (Parcel Drop mission, low over the marked field)
- **M** — mute, **R** — fly again after a crash or a finished sortie

Pick a sortie on the title screen: **Ring Run** (8 rings over the valley), **Parcel Drop** (deliver to the farm, then land), or **Dawn Landing** (circle the valley and put it down gently). Land on the runway to refuel; land hard anywhere else and the sortie is over.
